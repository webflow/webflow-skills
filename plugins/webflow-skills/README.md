# Webflow

Build and manage Webflow sites from your agent through the [Webflow MCP server](https://developers.webflow.com/mcp). Manage CMS content, audit site health, optimize assets, build Designer pages and components, create Code Components, run Webflow CLI workflows, and safely publish changes.

## Setup

After installing, open the plugin and click **Set up authentication**. Sign in to Webflow, choose the workspace or sites the agent can access, and paste the code back into the settings panel.

## What's included

- **Webflow MCP** connection at `https://mcp.webflow.com/mcp`
- **33 skills** for CMS, site audits, Designer, Code Components, Webflow CLI, and Webflow University guided activities

See the [full skill list](https://github.com/webflow/webflow-skills#skills).
